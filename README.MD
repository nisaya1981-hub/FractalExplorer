# FractalExplorer

**FractalExplorer** は、Eagle Mode に着想を得た **16:9 フラットズームビューポート（Zoomable User Interface）** を採用した次世代のファイルシステムエクスプローラーです。  
画面を深層ズーム（無限ズーム）していくことで、フォルダ階層やファイルの内容（テキスト・画像・動画・PDF等）をシームレスに閲覧・操作できます。

---

## 🌟 主な特徴

- **16:9 アスペクト比のグリッド自動レイアウト**
  - フォルダ内の要素数に応じて、最適なアスペクト比を維持しながら自動で敷き詰めて配置します。
- **マルチルート・ワークスペース**
  - 複数のドライブやフォルダを同時に1つの広大なキャンバス上へ追加し、横断的に閲覧・管理できます。
- **Box Drive (クラウドストレージ) 最適化**
  - オンライン専用ファイル（未ダウンロード状態のプレースホルダー）の誤発火を防ぐ安全設計。ズーム操作だけで勝手に大容量ファイルがクラウドから一括ダウンロードされるのを抑止します。
- **高性能レスポンシブプレビュー**
  - テキストファイル、画像（PNG/JPG/SVG/WebP等）、動画（MP4/WebM等）、PDFドキュメントをキャンバス上にダイレクト描画。
- **左右一体型のグラフィカルUI**
  - 左サイドバーに「フォルダ階層ツリー」と「詳細プロパティ」を配置し、メイン画面の Canvas ビューポートとリアルタイム連動します。

---

## 💡 内部構造：LOD（Level of Detail / レベルの概念）

FractalExplorer は、画面上のノード表示幅（ピクセルサイズ）に応じて自動的に描画モードを切り替える **LOD（Level of Detail）システム** を搭載しています。これにより、大量のファイルが存在する環境でも描画パフォーマンスを高く維持します。

### 🎨 3段階の表示レベル (LOD)

| レベル | ズーム状態（ノード表示幅） | 表示内容と動作 | 内部処理・パフォーマンス対策 |
| :--- | :--- | :--- | :--- |
| **Level 1** | **ズームアウト時**<br>(アイコン表示モード) | ・アイコン + ファイル/フォルダ名のみ表示<br>・ファイルの中身や画像は描画しない | ・メモリ/VRAM消費を最小化<br>・メディア（動画など）の再生を停止・破棄<br>・大量ファイル存在時は自動的にこのレベルを維持 |
| **Level 2** | **中ズーム時**<br>(プレビュー表示モード) | ・テキスト：冒頭数行のプレビュー<br>・画像：解像度を抑えたサムネイル描画<br>・動画：静止画（スチルフレーム）表示<br>・PDF：第1ページのサムネイル<br>・Box Drive：クラウド未保持カード表示 | ・遅延ロード（Lazy Load）の発火<br>・必要になったファイルのみディスク/メモリから読み込み |
| **Level 3** | **深層ズーム時**<br>(フルビュー & 対話モード) | ・テキスト：全行・フル解像度描画<br>・画像：高画質補正レンダリング<br>・動画：自動ループ再生（音声ミュート）<br>・PDF：Ctrl + ホイールでページ送り機能<br>・Office系：詳細フォーマットメタ表示 | ・アクティブなアニメーション描画ループ発火<br>・インタラクティブな各種対話操作が有効化 |

### ⚙️ 動的 LOD 閾値（Dynamic LOD Threshold）
1つのフォルダに含まれるアイテム数に応じて、Level 1 から Level 2 へ昇格する閾値（ピクセル幅）が動的に変化します。

- **アイテム数 30未満**: 表示幅 `240px` 以上でプレビュー表示
- **アイテム数 30〜100**: 表示幅 `400px` 以上でプレビュー表示
- **アイテム数 100以上**: 表示幅 `600px` 以上までしっかりズームインするまでアイコン表示（Level 1）を維持

## ⚡ メモリ & パフォーマンス管理機構

1. **Frustum Culling（視界外カリング）**
   - キャンバスの表示領域（画面外）にはみ出ているノードはレンダリング処理および動画再生を即座にスキップします。
2. **LRU Cache Manager（直近使用メモリ保持）**
   - 生成された画像オブジェクト (`imgObj`) や PDF Canvas キャッシュは **最大50件** まで LRU（Least Recently Used）アルゴリズムで管理されます。
   - 上限を超えた古いプレビューデータは自動的にガベージコレクション（`null` 化）され、長時間利用時のメモリ肥大化を防止します。

## 📖 操作方法ガイド

### 🔍 ナビゲーション（移動・ズーム）

| 操作 | アクション |
| :--- | :--- |
| **マウスホイール回転** | マウスカーソル位置を中心に拡大 / 縮小 |
| **左ドラッグ** | 画面のパン移動（平行移動） |
| **ノードを左クリック** | 対象ノードを中心にフォーカス＆ズームイン |
| **Ctrl + ホイール回転** | PDFドキュメント（Level 3ズーム時）のページ送り |
| **「Reset View」ボタン** | 視点を初期位置（全体表示）にリセット |

### 📂 ワークスペース操作

- **フォルダの追加**:
  - 上部バーの `+ Add Folder / Drive` ボタンをクリック、または OS からフォルダをキャンバス上へ**ドラッグ＆ドロップ**。
- **ターゲットパス検索**:
  - 上部検索バーにパスやファイル名を入力して Enter（または 🔍 ボタン）を押すと、対象ノードへ自動でフォーカス・ズームインします。
- **コンテキストメニュー（右クリック）**:
  - 関連アプリで開く / エクスプローラーで開く
  - 切り取り / コピー / 貼り付け
  - 新規ファイル作成 / 新規フォルダ作成
  - リネーム / 削除（ゴミ箱へ移動）
  - フルパスコピー / ファイル名コピー

## 🛠️ 技術構成

- **ランタイム**: [Electron](https://www.electronjs.org/)
- **フロントエンド**: HTML5 Canvas (2D Context), JavaScript (ES6+), [Tailwind CSS](https://tailwindcss.com/)
- **PDF レンダリング**: [PDF.js](https://mozilla.github.io/pdf.js/) (CMap 対応済み)
- **ファイルシステム連携**: Node.js `fs/promises`, Electron `ipcMain` / `ipcRenderer`
